小白龙娘 1.14.1 · Windows 10 / 11 x64

这是基于 T7moris/GPT-Niang Windows 原生版本的社区改进版，与 OpenAI 无官方关联。
保留原有音乐律动、图库、独立大小、拖动、自动语录、音效和完成提醒等功能。
移植 Mac 改进版的短按完整反馈、动画速度、三种彩蛋开关与次数、低额度形象、托盘额度和主窗口优先。

安装前请先安装、打开 Codex 桌面端并使用 ChatGPT 账号登录。
安装包内置经过官方 SHA-256 核对的 Node.js，无需另装 Node、Python 或开发工具。
按向导安装到当前用户目录；无需管理员权限。登录启动和桌面快捷方式由你勾选。
完成后，从开始菜单打开“小白龙娘”。在 Codex 主窗口内显示；也可以在右键菜单切换桌面模式。
托盘图标显示额度数字；鼠标停留可查看各窗口额度，双击查看气泡，右键刷新、打开设置或退出。

轻点会完整完成按压和回弹；可调 0.5–3 倍速，或立即到达按下姿态。
原位 stretch、兔兔跳舞、零额度拳击分别可开关，选择 1–10 次或持续循环，点角色可停止。
普通额度：伸缩与跳舞各 2.5%；新鲜有效且精确为 0 时三种均分总共 5%。不累计、不转移关闭项的概率。
跳舞保留原版 70 帧 / 7 秒；拳击保留 98 帧 / 9.8 秒。未重绘、插帧或改变原版速度。
剩余低于 5% 可切换形象并编辑台词，也可使用图库里的图片或导入本机图片。
原位伸缩示例备注：弹跳高松灯.gif；跳舞示例备注：兔兔.gif。

这是本地原生 WPF 应用。额度查询通过本机 Codex 的只读接口完成，Codex 会联网取得额度。
定制版关闭上游自动更新；手动检查会打开本项目发布页。作者与来源链接仅点击时在浏览器打开。
可选音乐律动会读取本机播放音频；完成提醒读取本地会话事件。请按需要开启。
用户设置与额度快照保存在本机 %LOCALAPPDATA%\GPTNiangUsage\state；不会随安装包分发。
卸载会停用本安装的插件、登录项和守护任务，保留个人设置和导入图片。

如果旧版安装在另一个目录，请先运行旧版的“停用GPT娘.cmd”，移除旧程序目录后再安装。
个人状态目录不需要删除。请勿在旧版仍运行时混用两个不同目录的安装。
此社区安装包未使用付费代码签名证书；Windows 可能显示未知发布者。请核对下载来源和 SHA256SUMS-Windows.txt。
