# 当前龙娘图片与图标的制作来源

当前 `gpt-dragon-niang-bust.png` 为维护者提供的普通立绘，内容原样保留。形象出处按维护者提供的信息署名 ZipZipPipe，Bilibili UID 4168597。文件 SHA-256 见 [USER-CHARACTER-SOURCE](USER-CHARACTER-SOURCE.txt)。

App 图标以该图片为输入，由程序绘制渐变圆角底板、阴影和边线，再缩放排版并导出 macOS 多尺寸图像；菜单栏图标由当前普通形象缩放。图标制作使用 Codex 辅助完成，角色设计来源与制作贡献分别记录，详见 [ICON-SOURCE](ICON-SOURCE.txt)。

当前坐姿 stretch 图片和低额度图片使用 ImageGen 根据维护者提供的角色参考生成或加工，原位伸缩运动由程序实现。低额度加工说明见 [low-quota-SOURCE](low-quota-SOURCE.txt)。当前兔兔跳舞与拳击使用维护者提供的原版 GIF，保留原帧和速度，来源见 [完整致谢](../../docs/CREDITS.md)。
