## 联网范围：不能写成“整个程序只访问 GitHub”

| 路径 | 实际行为 |
| --- | --- |
| 挂件 WebView | 只加载 App 内 `gpt-niang://widget/` 白名单资源；CSP 的 `connect-src 'none'` 禁止网页发起联网 |
| 额度查询 | 后台通过本机 Codex 的 `app-server --stdio` 发起只读请求。Codex 客户端会联网取得额度，具体账户服务、连接与客户端自身配置由 Codex 控制 |
| 自动／手动更新 | 本定制包的 `GPTNiangCustomBuild=true` 阻止更新下载；Mac 包不包含 Windows 的 `update.mjs` |
| 源码保留的上游更新实现 | HTTPS 白名单为 GitHub 上游 Release API／下载路径及指定 GitHub 下载 CDN；本定制包不启用这条下载路径 |
| 点击作者、作品和来源链接 | 用户点击后由外部浏览器打开 GitHub、B 站等对应页面，不由挂件后台自动拉取 |
| 从源码构建 | 构建脚本从 `https://nodejs.org/dist/v24.22.1/` 下载 Node.js 并核对官方 SHA-256 清单。预编译包已内置运行时，安装用户无需执行下载 |

本次用已安装的后台模块进行一次真实额度读取，记录发送的方法名、成功状态，并短时采样进程套接字；查询成功，观察到 Codex 子进程的远端 HTTPS（443）连接。没有记录原始账户响应、请求正文、令牌或聊天内容。套接字采样不等于完整抓包，也不能从 CDN IP 单独证明请求域名或全部未来行为。因此不能把“只访问 GitHub”作为整个运行链路的保证。

## 防御边界

- WebView 使用不持久化存储，拒绝远程导航、新窗口及子框架；原生桥只接受固定本地页面、主框架和 `ready / character / bubble / refresh / settings` 五种动作，不接收任意命令和文件路径。
- 台词以文本方式展示；额度状态通过参数传入 JavaScript，避免将用户文字拼成可执行脚本。
- 自定义图片通过原生选择器导入，限制 10 MiB、最大 4096 像素，重新编码为 PNG 并去除输入元数据；资源名限制为固定逻辑名或生成的 UUID。WAV 导入限制大小、5 秒时长及支持的无压缩格式，不调用外部编解码程序。
- 后台使用参数数组启动固定程序和脚本，没有 `shell: true`、动态代码下载或脚本求值入口。Mac 工作进程使用本地文件／标准输入输出及文件锁，不启动对外 TCP 服务。Windows 命名管道代码不在 Mac 路径上监听公网。
- 上游更新代码校验 HTTPS 目标、大小、摘要、ZIP 路径、重复条目和链接，使用带归属记录的更新暂存目录及回滚流程；本定制包阻止更新下载。
- 登录启动使用用户可见、可关闭的系统登录项；窗口跟随观察鼠标点击和窗口状态，没有键盘内容记录实现。检查范围内未见额外隐藏登录项、计划任务或 Mac 提权脚本。
- 包内 Node.js 为 v24.22.1，来源与官方分发包摘要记录在 `Node-SOURCE.txt`，许可证包含其所列第三方声明。该版本的 [Node.js 官方发布记录](https://github.com/nodejs/node/releases/tag/v24.22.1)为安全维护版本；本次没有对 Node、系统框架或 Codex 客户端本身进行完整独立审计。
