# 本次发布的安全与隐私检查

检查对象：当前 macOS WebView 定制代码、打包的 Node 后台脚本、发布应用及展示图。此记录属于发布前源码和包内容检查，不是第三方安全审计，也不承诺不存在所有漏洞。上游 Windows 代码保留为来源，本次结论针对实际发布的 Mac 包。

## 检查到的行为

- 额度查询启动本机 Codex 的 `app-server --stdio`，使用初始化、`account/read` 与 `account/rateLimits/read`；检查路径中未见模型生成或远程命令调用。
- 检查到的本地 WebView 仅加载白名单资源；CSP 禁止联网、表单、远程媒体和嵌入页面。原生桥限制在主框架、固定页面和五个动作，没有任意命令或任意文件路径参数。
- 自定义形象经原生文件选择器读取、解码为 PNG，限制文件大小和图像尺寸；WebView 使用固定逻辑资源名。用户台词用文本方式展示。
- 后台通过进程标准输入输出和本地文件队列工作。Mac 路径未启动对外 TCP 服务；上游 Windows 的命名管道不等同公网监听。
- 本定制包带 `GPTNiangCustomBuild` 标记，上游自动／手动更新下载路径被该标记阻止；新版本由维护者在本仓库准备。
- Node.js 运行时来自官方 HTTPS 下载，并由构建脚本与官方 SHA-256 清单核对；运行时来源、校验值及 Node 许可证随应用保留。
- 用户可自行开启系统登录启动；代码中未见额外的隐蔽登录项、提权脚本或计划任务用于 Mac 持久化。

在上述检查范围内，未发现明确的后门、额外遥测上传地址或 WebView 远程命令入口。Codex 客户端自身的联网和账户服务不属于本仓库可以保证的范围；本次没有完成全量流量捕获、第三方依赖审计或所有漏洞的证明。

## 应当了解的本地数据使用

额度查询不把原始账号字段输出给 WebView，按账号身份字段的 SHA-256 指纹区分本地快照。配置、额度快照、偏好和诊断保存在用户本机，未打包进本次分发文件。

上游保留的“聊天速度”面板会在打开时只读本地 Codex 会话索引、标题与 token 计数；可选的完成提醒会读取本地会话事件。它们涉及本地会话文件读取，不能把整个应用宣传成“完全不读取聊天文件”。检查代码中只向本机界面传递所需的标题、计数或完成事件，未发现把聊天正文上传到第三方的实现。

## 发布文件清理

- 不提交本机交接记录、安装日志、原始参考截图、账号配置、用户设置或快照。
- 原始截图的私人聊天、任务列表及账号区域不进入展示图；只保存经过遮挡的新像素图，未复制原图的 EXIF／XMP 元数据。
- 首次检查发现编译产物包含本机绝对构建路径。当前发布包已从不含个人目录名的临时源码目录重新构建，并在签名前剥离调试符号；重新扫描未发现原用户目录／附件预览路径。
- 检查发布包文件清单和常见凭证／私钥模式，未发现本机登录文件或凭证；打包的后台模块与对应源码一致。
- 保留用户主动要求公开署名的 B 站名字“邱会作”、UID 319500223，以及原作者的公开名字、UID 与项目许可。这些属于明确要求的署名信息。

## 验证边界

程序逻辑此前通过 150 项原生测试和 17 项构建入口 Node 测试。此次另核对发布包结构、签名、运行时模块一致性、个人路径和文件清单；对界面渲染图完成视觉检查。多屏／全屏组合和所有新增控件的完整鼠标验收仍未全部完成。

第三方图片与视频的版权许可不属于后门检查结论；跳舞片段已获得本项目用途同意，来源与范围另记于 ASSET-PERMISSIONS.md；仓库与 Release 继续保留私有草稿，等待维护者确认公开。

普通按压修复另通过真实 WebKit 与浏览器验证：同一帧的按下／松开仍完成压缩和回弹，立即压下可正常结束，偏好重启后保留。该改动仅增加本地动画计时与设置，没有新增联网或进程执行入口。

修复网页和彩蛋优先读取 App 内资源的路径。移开构建目录中的两个资源包后，使用隔离偏好的新进程启动已安装 App，WebView、后台和当前账号额度三项启动检查均通过；测试进程与隔离数据随后清理。

新增零额度分支仅在新鲜、有效、未过重置时间的额度窗口精确等于 0 时参与点击抽取；三种共用原来的 5% 概率区间，无累计和概率转移。动画素材与白名单均为本地资源；没有新增联网、远程输入或执行入口。当前拳击素材已重绘为白发龙娘，仍为 98 帧、9.8 秒，本次没有变更触发条件、概率或后台行为。
