以下模拟图由应用当前的本地 Web 组件与素材渲染，采用 2 倍像素密度，宽 2880 像素。数据为演示输入，不读取或修改真实账号额度。

## 正常、低额度和恢复

![额度状态模拟](images/demo-quota.png)

左侧示例为 72% / 89%；中间示例有一个有效窗口为 3%，展示低额度形象和台词；右侧示例有效额度恢复后还原普通形象。网络失败或旧快照不会被当成有效恢复。

## 菜单栏状态

![菜单栏模拟](images/demo-menubar.png)

这里模拟正常、低额度及暂未取得有效数据时的文字格式；是放大的排版示意。图标和百分比格式对应实际程序，系统真实尺寸和文字由 macOS 决定。

## 触摸板轻点

普通点击的压下和回弹不再被轻点的极短按住时间截断。设置 → 点击动画可选 0.5–3 倍速度，或开启“按下时立即到达压缩姿态”；连续点按更新当前反馈，不排队播放。此设置不改变随机彩蛋概率。

![普通轻点的完整压下与回弹](media/press-character.gif)

[播放带内置音效的点按演示](media/press-sound.mp4)。视频包含三次轻点，按下和松开分别使用程序自带 WAV 音效；GIF 不含声音。画面由实际本地组件渲染，72% / 89% 为模拟数据。

## 设置里的小彩蛋

![彩蛋和设置说明](images/demo-eggs.png)

这张图展示实际素材与设置要点，并非原生设置窗口截图。平时伸缩、跳舞各 2.5%；有效额度为 0 时，三种彩蛋各占总计 5% 的三分之一，不累积。每种可选 1–10 次或持续循环，也可关闭；再点人物可停止。
